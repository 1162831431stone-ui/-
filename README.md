# 📈 神奇的复利

> 让时间替你赚钱，而不是替你逝去。

这是一个纯前端的交互式复利计算器与资产组合模拟工具。通过可视化的图表和基于真实历史回报率的资产模型，帮助用户直观地感受到“时间”和“复利”在财富积累中的巨大力量。

## 🔗 在线体验 (Live Demo)

**[https://1162831431stone-ui.github.io/-/]（神奇的复利）**

## ✨ 核心功能 (Features)

* **📊 动态组合与实时计算**：自由配置多种资产（标普500、纳斯达克、苹果、英伟达、比特币、黄金、美债等）的投资占比，组合预期年化收益率实时刷新。
* **📈 可视化资产曲线**：直观渲染累计本金与复利收益的对比图，清晰展示“资金总额”随时间的非线性增长，以及“月光、存银行、定投”三种路径的巨大差距。
* **🎯 资产里程碑与财务自由节点**：自动推算资产突破 100 万、1000 万所需的时间，并计算“被动月收益超过工资”的财务自由临界点。
* **☕ 拿铁因子（机会成本）测算**：量化日常小额消费（如奶茶、冲动购物、订阅费）在复利周期下真正的机会成本。
* **📅 逐年账本**：提供详细的年度数据明细表格，直观展示“利息变本金”的逐年雪球效应。

## 🛠️ 技术栈 (Tech Stack)

* **前端UI与交互**：HTML5 + CSS3 + Vanilla JavaScript (零框架依赖，极速加载)
* **数据可视化**：[Chart.js](https://www.chartjs.org/) (CDN 引入)
* **部署方案**：GitHub Pages (纯静态托管)

## 🚀 本地运行 (Local Setup)

本项目为纯静态单页面应用，无需任何环境配置、Node.js 或数据库连接。
1. 克隆或下载本仓库代码到本地。
2. 双击打开 `index.html` 文件，即可直接在任何现代浏览器中体验。
